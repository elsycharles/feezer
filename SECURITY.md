# Security

Please do not report security problems in public issues.

Write to **elsy.s.charles@gmail.com** with a description of the problem and,
if possible, the steps to reproduce it. You will get an answer as soon as
possible, and a fix will be published in a new release.

Feezer has no server and no account: the app only downloads the public fee
grids from [feezer-fee-tables](https://github.com/elsycharles/feezer-fee-tables).
Release APKs are signed; the SHA-256 fingerprint of the signing certificate
is given in the notes of each release.
